Syntax reference

Variables

def x = 5 def name = "Ada" x = x + 1

Declare with def before use. def x alone starts at 0.

Output

print("x is " + x) alert(x)

Built-in functions take one argument. + joins strings.

Operators

+ - * / % ^ < > <= >= == != && ||

^ is power. Use ( ) for grouping.

If / else

cond x > 0 ? print("pos") ; cond x > 0 ? print("pos") : print("not pos") ; cond x > 0 ? print("pos") : x < 0 ? print("neg") : print("zero") ;

? then, : else, ; ends the block.

While loop

while i < 3 : print(i) i = i + 1 ;

: starts the body, ; ends it.

Comments

// line comment /* block comment */

Number literals are integers; strings use "double quotes".
